
# CodeVerse

An AI-powered competitive programming platform designed to help developers prepare for coding interviews and programming contests.

## Features

- Multi-language online compiler
- Live coding contests
- DSA problem library
- Company-wise problem sheets
- AI code review
- Leaderboards
- Real-time collaboration
- Docker-based code execution.

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- Docker
- Socket.io
